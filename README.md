# israelilori.com

My personal site: portfolio, project case studies and blog. It's plain HTML and CSS generated by one small Node script (`build.mjs`), so there's no framework to maintain.

## Where things live

| What | File |
|---|---|
| Name, intro, about, experience, education, skills, contact | `content/site.json` |
| Project case studies | `content/projects/*.md` |
| Blog posts | `content/posts/*.md` |
| Resume download | `static/resume.pdf` |
| Styles | `static/assets/style.css` |

## Write a new blog post

1. Create a file in `content/posts/` named `YYYY-MM-DD-short-title.md`.
2. Start it with this header, then write the post in Markdown below it:

   ```
   ---
   title: My post title
   date: 2026-10-05
   summary: One sentence shown in the post list.
   tags: data engineering, ClickHouse
   draft: true
   ---
   ```

3. Remove `draft: true` (or set it to `false`) when it's ready.
4. Commit and push to `main`. The site rebuilds and deploys in about a minute.

You can do all of this in the GitHub web editor with no local setup: open `content/posts`, choose **Add file → Create new file**, and commit.

## Add a project

Same idea in `content/projects/`. The header takes `title`, `org`, `period`, `order` (position on the home page), `summary`, `stack` (comma-separated) and an optional `status`.

## Deploy to GitHub Pages with your domain

1. Create a GitHub repository (e.g. `israelilori.github.io` or `website`) and push this folder to its `main` branch.
2. In the repository, go to **Settings → Pages** and set **Source** to **GitHub Actions**. The workflow in `.github/workflows/deploy.yml` builds and deploys on every push.
3. Buy the domain (e.g. `israelilori.com`) from a registrar such as Cloudflare, Namecheap or Porkbun.
4. At the registrar, add DNS records:
   - four `A` records for `@` pointing to `185.199.108.153`, `185.199.109.153`, `185.199.110.153`, `185.199.111.153`
   - a `CNAME` record for `www` pointing to `<your-github-username>.github.io`
5. Back in **Settings → Pages**, enter the domain under **Custom domain**, save, and tick **Enforce HTTPS** once it's available (DNS can take up to a day).
6. If your domain isn't `israelilori.com`, change `url` in `content/site.json` so the sitemap, feed and link previews use the right address.
